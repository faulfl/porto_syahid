# Portfolio Editorial — Tugas 1 Pemrograman Web

Versi desain yang lebih personal dan tidak menggunakan gaya "AI dashboard".

## Konsep visual
- Editorial / magazine
- Cream + black sebagai warna utama
- Red sebagai aksen
- Yellow sebagai highlight
- Blue sebagai aksen sekunder
- Layout asimetris dan whitespace
- Dekorasi dibuat menggunakan CSS, tanpa framework

## Warna
- Cream: #F5F0E8
- Black: #171717
- Red: #E6533C
- Yellow: #F0C94D
- Blue: #526FA8

## Teknologi
- HTML5
- CSS3
- Tanpa Bootstrap
- Tanpa Tailwind
- Responsive desktop dan mobile

## Cara menjalankan
1. Extract ZIP.
2. Buka folder `portfolio_editorial` di VS Code.
3. Buka `index.html`.
4. Jalankan dengan browser atau Live Server.

## Sebelum dikumpulkan
Ganti data contoh:
- Nama / inisial
- Deskripsi diri
- Email
- Project
- Riwayat pendidikan
- Informasi kontak

Periksa juga tampilan di desktop dan mobile.
